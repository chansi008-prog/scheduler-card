# 스케쥴러 및 도전카드

암웨이 사업자용 데일리 스케쥴 + 도전카드(사업 관심대상자 관리) 웹앱(PWA)입니다.
종이 플래너 대신 휴대폰에서 체크·선택·기록하고, **종이 양식과 똑같은 모양의 이미지**로 저장합니다.
iPhone은 Safari에서, Android는 Chrome에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

- 데일리: 시스템적 사고, 시급한 일(8시~10시 이후), 중요한 일 A/B/C와 상태(완료·연기·취소·위임·진행중), STP, 소비자 관리(합계 PV 자동), Call 10, 기억해두기
- 도전카드: 신/생/활, 관계 1~4, 동기 4단계, 목표, 방법·진행(질문과 결과 한 쌍), 소통 4단계, 피드백
- 사람 목록 하나를 모든 칸에서 같이 사용
- 복사 / 붙이기로 다른 날짜(다른 카드)에 내용 전체 옮기기
- 한 번 쓴 문구는 다음부터 버튼으로 선택

기록은 휴대폰 안(브라우저 저장소)에만 저장됩니다. 사람 탭 > 백업 > 내보내기로 백업하세요.
규칙 자동 테스트: `tests.html`을 열면 결과가 나옵니다.

## 파일
- `index.html` 화면 틀과 디자인
- `js/app.js` 화면과 입력 창
- `js/forms.js` 양식 규칙 (빈 양식, 합계, 복사·붙이기, 줄바꿈)
- `js/render.js` 종이 양식 그림 (이미지 저장)
- `js/store.js` 저장소 (나중에 서버로 옮길 때 이 파일만 바꾸면 됨)
