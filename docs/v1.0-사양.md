## 공통
- 아래 탭: 데일리 / 도전카드 / 사람 (v2.0에서 사람 → 설정)
- 사람 목록 하나를 모든 칸이 같이 씀. 고르는 창에서 바로 추가
- 한 번 쓴 문구는 다음부터 버튼으로 선택 (편집에서 하나씩 지우기)
- 복사 / 붙이기: 페이지 전체를 다른 날짜(다른 카드)로. 내용이 있으면 덮어쓸지 확인
- 이미지 저장: 실제 종이 양식과 같은 칸 구성, 가로:세로 1 : 1.414, 1748×2472 PNG. 글이 넘치면 그 칸만 글자가 작아짐
- 이미지 파일 안(iTXt)에 그 양식의 기록을 숨겨 둠 → 사람 탭 "이미지에서 되살리기"
- 백업: 내보내기/가져오기(JSON). 마지막 백업 후 7일 지나면 데일리 위에 알림, "나중에" = 하루 뒤
- 기록은 각 휴대폰(IndexedDB `scheduler-card`)에만 저장

## 데일리 (세로 양식)
- 날짜 → 요일 자동
- ★ 시스템적 사고 상자
  - 맨 위 줄 "시스템적 사고 : (요일 문구)" — 요일 문구 직접 입력, 다음에 선택
  - 저량 / 유입 / 유출 / 제어 / 피드백 5줄. 흐린 안내 글(이미지에는 안 찍힘)
    - 저량: 현재 상황 체크 / 유입: 오늘 할 것 / 유출: 상대가 할 질문 미리 생각해 보기 · 이탈 방지 / 제어: 주의점, 신경 쓸 것 / 피드백: 만난 후 체크 & 스폰서 상담
  - 참고: 원래 자료에는 소비자 / 후원 / 사업 3종류 시스템적 사고가 있었음 (종류 선택은 v1.0에서도 보류)
- 시급한 일(1상한) 8~10시 이후 1시간 단위 15칸, 글자 색 검정/빨강/초록
- 중요한 일(2상한) A·A·A·B·B·B·C·C·C·빈칸 10칸, 상태 V완료 / →연기 / ×취소 / 위임(맡긴 사람 성 한 글자 동그라미) / ●진행중, 글자 색
- STP 2줄 (사람 선택)
- 소비자 관리 5줄(이름·PV·전달 제품) + 개인 + 합계 PV 자동
- Call 10: 사람 + 한 일 + 연락함 체크, 최대 12명. 이미지에는 3줄 × 4칸
- 기억해두기 2줄, 글자 색

## 도전카드 (세로 양식, 상자 4개)
- 첫 화면: 날짜순 / 사람순 전환
- 일자, 대상(사람 선택)
- ★ 신 / 생 / 활 중 하나 선택 (뜻은 사용자 확인 대기였음). 이미지에 동그라미
- ★ 관계(발달 4단계): 개인적 1~4, 사업적 1~4 (4 = 상호 관계 좋음)
- ★ 상대 수준(나의 역할): 상대 / 나 직접 입력 (예: 0%, 잠재적 리더 / 사업지원, 멘토 및 가이드)
- ★ 동기(Process 4단계): needs / 준비 / 적용 / 결과 중 하나 — 상대가 지금 사업이 필요한가 / 준비하나 / 시작했나 / 결과가 나오는 중인가. 이미지에 ●
- ★ 1. 목표(What) 상자: 당월 / 익월 / 익익월(3등분), 저량(Level) / Why / 유입(What) / 유출(What)
- 2. 방법(How) · 3. 진행(doing): 질문과 결과를 번호별 한 쌍으로, 이미지에서 같은 높이
- 4. 피드백: 소통 4단계 1류 이해 / 2류 설득 / 3류 강요 / 4류 구박 중 하나(이번 소통 수준), 잘할 것 · 보완할 것
- (현 상황 칸은 교육자료용이라 v1.0부터 넣지 않음)
